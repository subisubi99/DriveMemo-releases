- 목록에서 메모를 위에 고정 (오른쪽 클릭 → 위에 고정) — 폴더 밖은 목록 맨 위 5개, 폴더 안은 그 폴더 맨 위 3개까지 (환경 설정 → 목록), 고정한 것끼리 끌어서 순서, 다른 PC와 같이

- 말풍선은 지금 보고 있는 창(메인 창·띄운 창) 안에 뜸 (예전엔 기능에 따라 다른 창에 뜨기도 했음)
- 말풍선 자리 고르기 (환경 설정 → 도움말): 자동 · 창의 여섯 자리 · 기능 바로 옆(예전)
- 말풍선 색이 테마와 살짝 달라 눈에 잘 띄게, 색 고르기 (자동 · 노랑 · 하늘 · 연두 · 분홍 · 메뉴 색)
- 기능 안내의 단축키를 쓰면 그 기능의 요령을 말풍선으로 (복사·저장·합치기·되돌리기·배율·완전 삭제 등, 도움말 수준에 따라)
- 최근 작업 기록을 한 줄에 하나씩 (시각 · 일어난 일 · 자세히), 줄을 고르면 아래에 파일·메모 이름 전체, [파일로 저장]
- 작업 기록에 빠졌던 일도 남김: 새 메모 쓰기·메모 고치기(메모마다 10분에 한 번)·즐겨찾기 표시·새 폴더
- 위쪽 [동기화 상황] 버튼 없앰 — 대신 [구글 드라이브]·[보조 백업] 연결 단추: 초록 연결 · 노랑 (연결 · 대기 n) 아직 안 올라간 내용 · 빨강 끊김, 누르면 동기화 상황, 오른쪽 클릭 = 데이터 폴더·설정 / 보조 백업 메뉴
- 사라진 말풍선을 F1로 다시 보기가 안 되던 곳 고침 — 묻는 창·그림 보기 창·PDF 보기·책갈피 이름 칸, 파일을 끌어다 놓은 직후
- 띄운 창에 파일을 놓고 묻는 창을 X·취소로 닫으면 뒤에 있던 다른 프로그램이 앞으로 나오던 것 고침
